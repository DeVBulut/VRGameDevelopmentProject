# 🥽 VR Sports Prototype – Unity Project (Meta Quest 3)

This repository contains a VR sports game prototype developed in Unity as part of a collaborative project. The game was designed for the **Meta Quest 3** and focused on basic environment interaction and VR presence within a sports context.

---

## 📘 Project Overview

This was an experimental prototype intended to explore building a sports-based VR game. While no polished gameplay loop or full mechanics were implemented, the project served as a learning opportunity for:

- Setting up a VR scene using Unity and the XR Interaction Toolkit  
- Working with Meta Quest 3 hardware and controls  
- Building a basic sports-themed VR environment
